# Prospective pure precision-gate core

Written before implementation and before any new historical forecast, target or score access. This module operates only on supplied vectors; historical issuance, eligibility, cold start, dates, memory windows and empirical registration belong to a separate caller.

Let b=baseline>0, a=adaptive>0, u=y/b>0 and r=b/a>0. All values and resulting ratios must be finite float64. For supplied finite state s, z=tanh(s), x_low=(1-z)/2 and x_high=(1+z)/2. Coefficients c=(c_low,c_high) lie in [0,1]^2, w=x*c, p=(1-w)+w*r and prediction=b/p. The positive sum form for p is algebraically 1+w*(r-1), avoiding cancellation near w=1 with tiny r. No clipping, epsilon, alternative model or arithmetic fallback.

Fit minimizes mean[u*p-log(p)] + .005*(c_low^2+c_high^2). Its full gradient is mean[(u-1/p)*(r-1)*x] + .01*c. Its Hessian is mean[((r-1)*x)^T*((r-1)*x)/p^2]+.01*I, hence strict convexity. Constant mode constrains c_low=c_high=c and optimizes one scalar with objective penalty .01*c^2; the optimization gradient is the sum of full gradients. This exact nesting is tested. For identical experts, the penalty gives the unique zero coefficient solution.

Only float64 bounded L-BFGS-B is permitted, starting at zero, ftol1e-13, gtol1e-9, maxiter1000, analytic gradient. Require solver success and projected-gradient infinity norm <=1e-8, calculated as theta-clip(theta-gradient,0,1) on the actual optimization coordinates. Failure raises; no fallback. The coefficient-box projection here measures constrained stationarity, not a repaired fitted coefficient. Input vectors must be aligned, one-dimensional real numeric nonboolean and finite; forecasts/targets strictly positive; fitted vectors nonempty. Prediction permits aligned empty applications. The constant flag is an exact bool. Returned coefficients remain exactly in their bounds.

API: fit_gate(base,adaptive,y,state,constant=False) returns a dict with coefficients [low,high], constant, objective, gradient (full two-parameter gradient), optimization_gradient (one scalar in constant mode, otherwise both), projected_gradient_max_abs, n_train, n_iterations, solver='L-BFGS-B', success=True. predict_gate(base,adaptive,state,coefficients) returns a positive finite float64 vector. Inputs are not mutated. The internal objective/gradient is independently checked by the prewritten tests; it is not a public data admission API.

Generated tests must precede implementation. They cover an independently derived interior optimum, scalar bounded Brent and independent SLSQP optima, analytic gradient and Hessian against literal finite differences, coefficient and QLIKE identity/nesting, endpoint and identical-expert optima, common-unit scaling, row permutation, changed application independence, literal invalid data/flags/coefficients, tiny-ratio endpoint cancellation, source-input preservation, exact solver settings, and rejected solver/stationarity failures. These are pure mathematical tests, not historical forecasting evidence or a registration. No empirical family or frozen source is modified.
