# Independent issued-calibration verification

This specification and its synthetic tests precede any historical calibration computation. Earlier frozen code and results remain unchanged. The independent verifier imports frozen mathematical helpers, but does not import the new producer, its admission implementation, or its scoring functions to reconstruct results.

The source layer independently follows the seven anchored wave18 documents, all recursively referenced report-manifest hash groups, the original freeze/test evidence, reviewed publication documents and figures, and the ten explicitly verified output hashes. Legacy bounded-content provenance hashes are not substituted for raw-byte hashes. Canonical paths, conflicting hashes, symlinks, duplicate JSON keys and nonfinite JSON are rejected. Every numerical output is decoded from the same bytes checked against its declared hash, only after the entire closure is registered. Hashes and absence of an upstream canonical failure are checked again after decoding and before committing a new verification. Original source values are not reparsed and prior models are not refitted.

All original monthly training masks, feature geometry and application dates are reconstructed. Every baseline logit comes from that application's original saved curvature centers, population scales and coefficients. Its saved application probability must replay at relative tolerance `1e-10` and absolute tolerance `1e-12`. Every original scored row must agree with its application audit; original baseline and recent-frequency control rows are preserved exactly. Full original event-rate states are checked by explicit weighted sums, without fitting their controls.

Calibration begins with empty issued-error history at the first application's prior-session cutoff. Each later observed reference close is classified once: no original issuance means `NO_ISSUED_FORECAST`, an issued forecast with an unknown label means `UNKNOWN_LABEL`, otherwise the record is admitted. The latter requires its actual label availability no later than the current cutoff. Feature gaps, unscored applications and missing arrivals retain the full session clock. The broader original recent-frequency information set is intentionally preserved.

The independent weights are explicit `(1-delta)*delta**age`, with `delta=2**(-1/63)`, calculated from the full reference calendar. They are not normalized. Weighted losses and stable signed residuals use compensated sums. Nonzero weighted products and saved-coordinate divisions may not underflow silently. Finite-logit signed softplus and signed residuals must remain nonzero; an extreme correctly classified logit whose loss underflows is rejected. Rounded forecast sigmoid endpoints remain admissible when their original finite logits retain representable stable losses and residuals. Inverse sigmoid and probability clipping are never used.

The scalar derivative is solved independently by bisection on `±(sum(weights)+1)/.02`, using `xtol=1e-12`, `rtol=1e-14`, and at most 200 iterations. Strict endpoint signs, convergence and the original full-gradient bound `1e-8+1e-12` are mandatory. Empty history and exact computed balanced gradient at zero retain zero corrections. There is no fallback or restart. The producer's distinct Brent solve must respect its declared method, bracket and numerical budget: empty/balanced branches have zero iterations and calls; fitted branches have positive integer counts within the fixed iteration/evaluation limits.

Only objective and gradient determine numerical admission. The mathematical curvature bounds are `.02` and `.02+.25*sum(weights)`; an unused weighted Hessian must not add a separate underflow rejection. A prewritten `eta=700, y=0, weight=1e-40` regression specifically checks this distinction. Other peer-review regressions cover lost saved-coordinate divisions and an upstream failure marker appearing during output decoding or before final publication.

Saved weight mass is compared with explicit reconstruction under the fixed `64*(elapsed_sessions+1)` epsilon/downward-ULP envelope, preserving exact zero/sign masks. Saved scalar objectives, gradients and original logits replay at `rtol=1e-10, atol=1e-12`; independent coefficients use `rtol=1e-7, atol=1e-6`. Corrected probabilities use the strict `1e-10/1e-12` comparison after literal domain checks. Exact zero correction copies the original saved probability bit-for-bit; nonzero correction exactly replays the sigmoid of the audited finite logit plus the saved intercept. Brier losses replay exactly.

The verifier reconstructs both controls in both phases, all fixed later slices, 12 bootstrap runs of 199,999 draws, HAC126, absolute `.0005` effect requirements, wave Holm2 and cumulative Holm131. It preserves all129 earlier hypotheses, including failures. Calibration in the large and nominal detectable effect remain descriptive. Six new output/metrics/ledger byte hashes are checked at completion and serialized in the successful verification record. Any failure preserves only diagnostic output and replaces this wave's canonical publication with both new p-values equal to one.

Tests were written before each implementation or identified correction, with initial failures retained. Generated integration verifies all original applications, mature-record selection, independent scalar roots, unchanged controls, future-data invariance, phase inference and mutation rejection. Whole-entry tests check the exact artifact paths and final hash evidence. These tests establish implementation behavior, not an empirical result, a new independent information source, or untouched future validation.
