# Prospective admission of the original alert records

This is the source and proof design for a prospective event-cluster experiment, with a new implementation tested on synthetic temporary records. It is not registration, actual historical source admission or a new empirical result. The documentary review inspected existing code, protocols and published proof metadata only. It did not decode actual market, feature, target, forecast or state tables; collect an actual new closure; count new events or support; compute associations; or refit any model. All earlier files remain unchanged.

The usable records are the unchanged wave18 SPX alert features, targets, original monthly coefficients, application states and issued baseline/recent-frequency probabilities. Wave19 supplies the latest successful verification, complete inference history and preservation envelope. Its calibrated probabilities are not a replacement baseline. Any use of that extra model would have to be an explicit registered comparison.

## Two proof layers, no old optimizer

The frozen [issued-calibration admission module](/Users/byrons/code/trading-vol/ndx-vol-experiment/src/issued_calibration_admission.py) already implements `collect_input_pins(root, expected)` and `admit_upstream(root, expected, registered_pins)`. The latter returns `(audit, loaded)`, including the original full wave18 feature/target calendars, forecast panel, states, fit list, original protocol, support/source audits, metrics and ledger. It hashes sources and decodes checked buffers without reconstructing labels, historical logits, or prior fits. Its [source design](/Users/byrons/code/trading-vol/ndx-vol-experiment/reports/issued_calibration/SOURCE_DESIGN.md) documents the exact existing contract.

That module is intentionally specific to wave18: its seven permitted anchor paths and ten verified-output paths are literal. Passing wave19 paths as its `expected` map is not a valid extension. A new, additive outer admission layer should:

1. Check the new protocol's literal wave19 anchor bytes before decoding their metadata, and verify their success/status/backlink identities.
2. Build and check the complete wave19 raw-byte dependency closure and six verified outputs described below. Every member must have the same hash in the new registration input inventory before output decoding.
3. Call the frozen wave18 admission using the original wave18 anchor map from the checked wave19 protocol. Its returned deterministic audit must exactly equal the decoded, hash-pinned `data/issued_calibration/upstream_admission.json`. This binds the original inputs used for the wave19 proof to the wave18 records now reused.
4. Return the original wave18 loaded records, together with a distinct outer wave19 audit. Do not call either old verifier's `verify()` entrypoint or any old forecast/refit routine. Those entrypoints write old proof files and/or reconstruct old numerical models.

The new verifier shares the metadata-only closure traversal and separately rehashes the literal anchors and complete declared file closure before and after admission. This source bookkeeping is not an independently implemented parser. Numerical memory, offset, stage, prediction and inference reconstruction are independent. Existing wave18/wave19 coefficient, probability and target proofs are accepted by exact identity; this does not require running the earlier optimizers again. The new model still has to prove its own timing, state, original-issued-logit mapping where needed, forecasts and inference independently.

## Causal information boundary

The asset remains the archival raw SPX cash price index, with the original daily OHLC proxy and admitted Cboe controls. No ETF/futures substitution, live dissemination claim, source-vintage refresh, purchase or provider acquisition is needed. Keep the original source fence through 2025-10-20 and sealed period beginning 2025-11-03. Reusing checked bounded tables does not authorize parsing protected raw numeric rows.

For origin `t`, the original alert is `V[t+1] > 2 * mean(V[t-22:t-1])`, with exact original arithmetic and original next-SPX-session close as label availability. All new state must be computed by the previous observed SPX-session cutoff before examining the query label. The full reference calendar and all original applications, including unscored applications, must remain intact. Unknown labels are not zero; missing/unknown dates still age a clock-based state. No future observed session is a predictor.

The source layer preserves distinct history sets. The parent has selected broad mature known-target history for the new event-cluster state, including dates without a baseline issuance or complete features; the new protocol must freeze this explicitly. This is not issued forecast-error memory. If a fit also uses an original issued logit, that record additionally requires an actual baseline issuance and its matching original fit/probability; no retrospective probability may be fabricated for feature-incomplete or unissued dates. The original recent-frequency control intentionally has a broader known-label pool than issued-error calibration. A new matched mechanism control must keep these information-set choices explicit; source admission must not silently decide them by intersecting tables.

The preserved labels support testing conditional predictability of this particular relative-risk event. Their overlapping trailing-22 reference can itself create persistence. Even a verified incremental gain would not identify structural event self-excitation, forecast integrated variance, establish an external information channel, or establish trading profit. Archived walk-forward issuance is not a contemporaneous live forecast record. Earlier Yahoo/Cboe revision and publication-latency uncertainty, back-calculated early VIX9D, repeated history reuse and adaptive mechanism selection remain unchanged.
