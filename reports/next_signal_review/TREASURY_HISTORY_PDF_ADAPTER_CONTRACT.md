# Treasury PDF metadata adapter

`inspect_pdf(text: str, *, result: bool, expected_cusip: str)` returns exactly `header`, `release_date`, `cusip`, `amended`, and `fields`. This is a new bounded extractor; frozen helpers, source bytes and saved text remain unchanged. No historical document was passed through this implementation during development.

`fields` uses the literal keys `Term and Type of Security`, `Auction Date`, `Dated Date`, `Issue Date`, `Maturity Date`, `Original Issue Date`, and `Series`. Values retain source lexemes after trimming outer whitespace. Dates remain English PDF date strings and must describe valid calendar dates. `Original Issue Date` and `Series` are optional; results may also omit `Auction Date`. No missing field is fabricated. The auction date, if present, is within 2010-01-01 through 2025-10-20; issue and maturity dates may be later. Cross-document date/term/lineage agreement remains the caller's responsibility.

The standard layout reads exact labeled rows. The separately reviewed column layout uses the fourteen value lines immediately following the supported heading (with an optional standalone offering footnote marker `1`) and the exact subsequent fourteen-label block. The block is: Term and Type of Security; Offering Amount; Currently Outstanding; CUSIP Number; Auction Date; Original Issue Date; Issue Date; Maturity Date; Dated Date; Series; Yield; Interest Rate; Interest Payment Dates (observed optional footnote `4`); Accrued Interest with its two displayed dates. Empty cells, missing/reordered/duplicated labels, unexpected block lengths and additional own metadata labels outside the block fail.

Only the requested metadata cells are returned. Offering, outstanding, yield, rate, payment and accrued cells are positional structure; their contents are never numerically converted or exposed in the output. The own CUSIP comes from its own row or fixed column position, independently of the supplied expected identity. An expected CUSIP found elsewhere cannot repair a mismatch. Corpus identifiers and supplemental `CUSIP Number(s)` rows never supply own identity. Duplicate, empty and conflicting own fields fail.

The accepted titles are `TREASURY OFFERING ANNOUNCEMENT`, `AMENDED ANNOUNCEMENT`, and `TREASURY AUCTION RESULTS`, with the requested role enforced. Every amended announcement returns `amended: true`; this flag does not itself authorize that amendment. Root must bind each such event to reviewed dated amendment evidence before admission. Results require their ordinary result title.

The header retains the frozen probe's explicit release-label and date evidence. Its `cusips` list is rebuilt from the independently extracted own field, never from the expected value; raw text is not rewritten to make the frozen probe succeed. The frozen identity validator enforces the existing unique dated-release scope. Release dates and printed embargo/bid deadlines do not establish historical delivery timestamps.

Eleven generated test methods were written before the module. The saved RED is the genuine missing-module import failure. After implementation, formatting and import cleanup, all eleven pass; the scoped GREEN log records the final timing. Ruff checks pass for the two new Python files. Coverage includes standard rows, both observed column title forms, optional result fields, exact metadata mapping, opaque pathological financial cells, supplemental-identifier rejection, expected-value decoys, duplicate/empty fields, column-shape failures, role/amendment flags, calendar validity and bounded typed inputs. No source histories, financial conversions, model calculations, full suite or historical adapter application ran.

Before freeze, an independent review identified that punctuation forms such as `CUSIP: ZZ1234567` could be detected by the frozen probe but ignored by the new field scan before header reconstruction. A prewritten twelfth method tested four punctuation forms, repeated or conflicting values, and both standard-result and column-announcement layouts. Its separate `OWN_LABEL_REGRESSION_RED.log` records eight failed rejection subcases before the correction. Unsupported own-CUSIP label forms now raise, including outside the column block; only the exact supplemental `CUSIP Number(s)` label is excluded. All twelve scoped methods then passed in the separate regression GREEN log, with Ruff clean. The initial eleven-method evidence remains unchanged.
