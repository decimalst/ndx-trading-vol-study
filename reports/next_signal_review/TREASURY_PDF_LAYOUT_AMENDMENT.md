# PDF metadata layout refinement before numerical table review

The strict initial probe preserved 24 header-review cases. Metadata-only diagnosis, with all digits masked when examining header wording, establishes two format distinctions: offering notices say `Embargoed Until` rather than `For Immediate Release`, and separately labeled Corpus CUSIPs refer to stripping identifiers rather than the auctioned security. A special notice's narrative also contains dates that are not its release date. One 2019 text layer spells the marker `FOR I.MMEDIATE RELEASE`.

The additional prewritten layout tests require the date immediately below the explicit release/embargo marker, stop before title/body content, and restrict the security identifier to its own line beginning `CUSIP`. Adjacent competing header dates remain ambiguous. The original probe, output and checkpoint are preserved. This improves documentary classification without altering source values, proposed features or predictive gates.

The latter is not substituted into the announcement. The original image and XML must be compared and any unresolved conflict retained explicitly.

This documentary evidence supplies a classification question for visual review; it is not a newly measured predictive effect.
