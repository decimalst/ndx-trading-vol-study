# Fixed Treasury document capture and blind schema inspection

This is the next source audit, not numerical admission or a predictive experiment. The immutable 22-record pilot selected from dates, identities and links contains 118 associations with 116 unique PDF/XML URLs. Selection hash: `25d2ff3b2a619fe84e4354b9269826be8f007a55065123fc7bc41c134b45f417`. Use precisely those URLs once each, retaining their multiple event/kind associations. No guessed replacement, broader endpoint or updated current history is used.

Before the requests, synthetic contracts cover URL identity, exact official host/path/year, event dates within 2010-01-01 through 2025-10-20, malformed/post-ceiling filename dates, duplicates, transport receipts, empty versus present documents, body limits, hashes and no numerical export. Every selected event is date-preflighted before constructing requests. Known future issue/maturity dates inside documents remain permissible descriptors, but auction/public-release dates after the ceiling are not source-value inputs.

The certificate-verified HTTP client uses no redirect following or disabled certificate checks, at most three simultaneous requests, a 45-second transfer limit, and 2 MiB XML / 8 MiB PDF limits. Save original bytes, headers, receipt, requested/effective URL, UTC retrieval time, byte count, hash and transport errors under ignored `data/source_discovery/treasury_auction/document_pilot_v1/`. Existing output directories/reports stop replay; an individual failure remains recorded while independent documents can finish. There is no automatic retry or missing-document substitution.

PDF capture checks only transport, content type and byte signature. It does not yet establish that a PDF is the right original release. XML capture checks transport and extracts only root/tag paths, occurrence counts and attribute names. No XML text, attribute values, comments or tails are exported. DTD/entity declarations, malformed XML and invalid UTF-8 fail this blind schema pass. Numerical text is never converted into numbers. A schema-only success is not a statement about auction content or historical availability.

After the structure is known, prewritten document metadata guards will authenticate literal date/identity/class fields before any financial amount is converted or visually inspected. PDF page layout will then be checked against XML, using original bytes and the locally available PDF tools. Inspect actual release/addendum dates, original-term identity, correction and special-notice relationships; filenames and current-index display labels alone are insufficient. The June 2019 extra event and 2025-01-27 suffix mismatch are retained for content classification, not automatically repaired or excluded.

The independent `TREASURY_PILOT_REVIEW_CONTRACT.md` fixes the documentary questions. A fixed sample cannot establish full-history correction completeness: all relevant known special notices must eventually be classified before source admission. The source must retain unresolved originals/date conflicts as unknown. No model feature, target panel, fit, score or acceptance gate is produced by this checkpoint; registered comparisons stay at 144.
