# History offering adapter

`reconcile_history_offering(pdf_text, announcement_xml, result_xml, *, identities, xml_unit)` preserves the exact result schema and financial arithmetic of the frozen offering reconciler. Only the newly authenticated PDF layout path is added. Existing PDF adapters, offering helpers, source documents and extracted text remain unchanged.

`identities` has exactly `announcement_pdf`, `announcement_xml` and `result_xml`. Each contains its own explicit auction date, announcement date and CUSIP; the XML contracts also contain `announced_cusip`, with `None` representing the exact empty source field. The PDF's expected announcement date is its actual PDF release date. Each XML retains its own original archive announcement date. The outer identity pass must authenticate any amendment, revised-date or announced-to-realized security relationship; this adapter neither infers nor admits that relationship.

The PDF adapter inspects the original complete text, checks its own announcement role and CUSIP, and supplies the auction-date field and explicit release date. Both dates must match the PDF's separate expected identity. For ordinary rows, Offering Amount must be one exact, nonempty labeled field. For the already validated fourteen-cell column block, its value is fixed cell 1, immediately after the term cell. No expected-amount search, number matching, supplementation or raw-text rewrite occurs. Duplicate, empty and aliased Offering Amount fields fail. Supplemental CUSIP fields cannot replace or conflict with the own identity.

The frozen `_xml_token` checks the original announcement and result XML independently, including exact dates/CUSIPs, AnnouncedCUSIP, role containers, unique direct OfferingAmount and unaliased leaves. All three source identity/container checks finish before any `_answer` financial conversion. The only allowed XML scale contract is the literal `USD_BILLIONS`, with the frozen exact 1e9 mapping and integer-dollar arithmetic. All three stated amounts must agree exactly. The result retains source tokens, units and the qualification that the scale is a PDF-checked mapping hypothesis, not universally authenticated XML schema units. `source_admitted` remains false.
