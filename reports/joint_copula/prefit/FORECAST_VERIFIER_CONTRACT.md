# Independent joint-copula forecast and mathematical verification

This contract and all implementation tests use generated observations only. No wave27 empirical source array, support, fit, forecast or score was inspected. Work stays in the new verifier, its tests and new prefit reports; frozen source/model artifacts remain unchanged. The repository was on main with an existing mixed worktree; Python3.11.7 in .venv was used. No staging, commit or publication operation was performed.

Public APIs are `independent_log_copula(z,rho,family)`, `verify_dependence(z,family,rho,audit)`, and `verify_forecasts(qqq,spx,iv,produced,config=None)`. The two fitted mathematical families are literal `t8` and `gaussian`. The full forecast arms are `t8_copula`, `gaussian_copula`, and `independence`. A successful verifier returns VERIFIED plus explicit counts and limitations; a source, measurement, timing, parameter, certificate, schema or numerical discrepancy raises. It does not relabel a failed or partial pipeline as a successful forecast history.

The independent module imports no new copula density, model, feature, pipeline or score producer. It explicitly reuses the frozen independent `verify_joint_risk.feature_target_tables`, `transform` and `verify_moments` oracles. These retain the original full-SPX-calendar measurement and predecessor rules, all34 raw features plus the training-centered correlation square, augmented least-squares mean reconstruction and independent convex positive-moment reconstruction. The typed recursive identity comparator from the independent claims verifier is also reused. Producer calls occur only in generated agreement/corruption tests.

All raw source calendars are checked before numerical or measurement operations: native naive midnight, unique, increasing and no later than the passed source ceiling or fixed2025-10-20. The complete independent measurement gate precedes feature selection. Every full-calendar feature and next-session paired signed target, including missing values and exact predecessor/maturity dates, is compared. A missing QQQ source predecessor is preserved; the reference calendar is never intersected or compressed.

The six configuration fields are origin_start, origin_end, source_end, development, evaluation and minimum_train. Fixed defaults are origin2016-01-04..2025-10-17, development2016-01-04..2019-12-31, evaluation2020-01-01..2025-10-20, source ceiling2025-10-20 and minimum1000. Smaller generated windows/floors are allowed solely through explicit synthetic configuration; root authenticates the actual production protocol. Each month's first requested common-feature-complete origin schedules the fit without its query label. All complete requested queries are issued. Training contains every common-feature/paired-target-complete earlier origin whose next-session label matures by the fit's preceding full-calendar session. The exact origin/position lists and every schedule, fit, coverage row, scored row and unscored application are reconstructed.

Each marginal audit is schema checked and independently reconstructed. Dependence residuals use the independently checked saved marginal coefficients: current-fit in-sample mean errors divided by sqrt(.75*h). This is deliberately not an issued-error ledger. All three arms must have exactly identical saved mu/h at every query; independence has the exact zero placeholder and each fitted arm has one constant rho per monthly fit. ## Independent mathematics

For t8 the inverse-t8 of its own CDF is the identity. The joint log density is evaluated with scaled positive sum/difference quadratics; each marginal log kernel uses logaddexp. For the Gaussian transform, the smaller t8 tail uses the incomplete-beta identity `I_w(4,1/2)=w^4*2F1(4,1/2;5;w)/(4*B(4,1/2))`, evaluated in log space, and `ndtri_exp` inverts its log CDF. The verifier uses direct stdtr on the central |z|<sqrt(8) branch and the hypergeometric identity outside; this independent numerical branch differs from the producer's threshold1 without changing the distribution. No CDF endpoint is clipped. Generated residuals as large as1e200 retain finite densities. Gaussian rho0 is exactly independent; t8 rho0 is not.

Writing `s=mean(w1²+w2²)` and `c=mean(w1*w2)`, Gaussian stationary correlations solve `rho³-c*rho²+(s-1)*rho-c=0`. Every root, polynomial, admissible candidate, both endpoints and zero are reconstructed, including the prescribed tie rule. A generated small-variance symmetric example has three real stationary points and two competing minima, so agreement with one local stationary solution is insufficient.

For t8, let `A_i=8*(1-rho²)+z1²+z2²-2*rho*z1*z2`. Apart from rho-independent terms, NLL is `5*mean(log(A))-4.5*log(1-rho²)`. Its gradient is `5*mean(A'/A)+9*rho/(1-rho²)`; its Hessian is `5*mean(-16/A-(A'/A)²)+9*(1+rho²)/(1-rho²)²`. On each interval the concave A has endpoint minimum, while |A'| has endpoint maximum. These give a lower Hessian bound, improved by the smallest positive Hessian term at the interval point closest to zero. Minimizing the resulting midpoint Taylor quadratic supplies a lower objective bound. Scaling each row by max(1,|z1|,|z2|) makes the same argument numerically stable.

The verifier independently reconstructs every final interval's midpoint, complete NLL including constants, gradient, curvature lower bound and roundoff-inflated objective bound. It requires ordered contiguous nonoverlapping coverage of the entire[-.995,.995] domain, splits+1 leaves, the fixed32768 budget, and the reconstructed global gap<=1e-8. Projected stationarity must be<=1e-7 with correct boundary signs. Saved optimizer messages are type/status checked, not falsely reproduced; the full-domain certificate establishes numerical optimality independently of that diagnostic. This is a floating-point certificate, not a formal exact-arithmetic proof.

## Fixed pre-empirical tolerances

Direct saved mu/h/rho replay uses absolute1e-12, relative1e-7. Feature/target arithmetic uses absolute1e-12, relative1e-9. The inherited marginal oracle keeps its original, distinct tolerances: mean coefficients/predictions absolute1e-10, relative1e-7; variance coefficients absolute1e-6, relative1e-7; independently optimized variance predictions absolute1e-12, relative1e-6; variance geometry/objective absolute1e-12, relative1e-9; reconstructed KKT diagnostics absolute1e-12, relative1e-4. No parameter is adjusted after empirical inspection.

The initial eight mathematical tests precede the module; `FORECAST_VERIFIER_RED.log` records the genuine missing-module failure. The four certificate and eight original forecast tests precede those functions; `FORECAST_VERIFIER_CERTIFICATE_PIPELINE_RED.log` records both missing-function failures. The first mathematical implementation passed8 tests. The first certificate run rejected the producer's exact factor256.0 because the verifier had unnecessarily required an integer type; accepting that fixed finite real factor corrected only the schema assumption. Its failure is preserved in `FORECAST_VERIFIER_CERTIFICATE_FIRST.log`; the subsequent original20 tests all passed.

Before freeze, comparison with the root's explicit execution metadata led to the prescribed tighter direct forecast tolerance. Two prewritten tests first exposed permissive tiny-variance absolute comparison and strict-domain violations (`FORECAST_VERIFIER_OUTPUT_DOMAIN_RED.log`). Another prewritten test exposed allowing tiny cross-arm marginal differences and a nonzero independence placeholder on unscored origins (`FORECAST_VERIFIER_SHARED_IDENTITY_RED.log`). These were corrected before empirical use. A generated six-Parquet-plus-fits-JSON roundtrip was added as pre-empirical coverage and passed its first run; no false RED is claimed for that test.

Final evidence:24 generated tests passed in1.638 seconds, followed by clean scoped Ruff and formatting checks in `FORECAST_VERIFIER_FINAL_GREEN.log`. They include separate scipy density ratios, marginal-preservation quadrature, finite-difference derivatives, interval bounds, domain/schema/certificate corruption, original-calendar missingness, target-blind scheduling, exact training membership, staged marginal fits, partial/unscored application completeness, zero placeholders and saved-format reconstruction. No full repository suite or historical model was run by this reviewer.

Source hashes and historical-vintage authentication remain root-owned. Statistical support/inference is a separate independent check. Reused history, previously accessed later outcomes, current vendor vintages, QQQ-versus-SPX instrument distinctions and imperfectly specified marginals limit interpretation even if every numerical check passes. A computationally verified dependence gain would not identify pure tail dependence or tradable profit.
