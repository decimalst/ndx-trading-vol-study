# Independent pre-fit design review

Status: ready for independent verification and root-controlled freeze. This review found no blocking mismatch between the new protocol, feature construction, models, and runner. It used source methodology and code plus synthetic tests; it did not inspect empirical event counts, residuals, fits, or predictive associations.

The question is deliberately narrower than general volatility forecasting: can one lagged SKEW-dependent shape slope improve a signed next-session downside event forecast while both density arms retain identical predicted mean and variance? SKEW reflects an option-based, risk-adjusted 30-day skewness construction. It is not itself a physical one-day crash probability, and its numerical sign need not equal the fitted physical-density shape coefficient. [Cboe SKEW methodology, definition on page 5](https://cdn.cboe.com/resources/indices/documents/SKEWwhitepaperjan2011.pdf)

The source contract pins the existing raw SKEW hash, metadata URL/date coverage, historical anchor, and bounded agreement with the existing derived file. The raw CSV supplies the predictor; the derived file is an integrity check. CSV date tokens are selected before numeric conversion, and bounded parquet filtering preserves the October 20, 2025 source fence. The runner hashes all seven source paths, three Cboe manifests, and the SPX source manifest. These checks establish consistency with the archived inputs, not original historical vintages. Yahoo/Cboe revision and exact release latency remain unverified. The VIX9D back-calculated period remains explicitly archival training information, with no contemporaneous 2011 availability claim. No fresh market-data download is authorized by this review.

All market predictors and the strict 22-observation return normalizers stop at the preceding observed SPX session. Current entry weekday is known. The target uses the next raw close return, with no dividend or interest adjustment, and the binary event is exactly normalized return below −1.5. It is neither a fitted quantile nor a universal 5% VaR threshold. Training labels must mature by the previous session of a monthly fit; application scheduling depends on complete features before future label readiness. Development labels also mature within development. Missing calendar positions remain in strict windows. All three arms share the same complete rows, and minimum class support is checked for training, both phases, and both evaluation slices without lowering any threshold.

The common conditional mean uses fixed ridge regularization; the positive variance model fits squared residuals from that same training fit. These are in-sample training residuals, explicitly labeled as such. Training-only centering/scaling includes separate implied-risk, realized-risk, and SKEW curvature controls; zero scales abort. Both density arms reuse exactly the same fitted mean and positive variance. The Hansen distribution preserves those moments for each shape value, including the density scale Jacobian. Degrees of freedom are fixed at eight. One shape slope, coefficient bounds, slope penalty, fixed starts, optimizer budgets, and projected-gradient tolerance are registered; no fallback, multistart, or post-fit tuning is allowed. A stationary fit does not establish a global optimum. Remaining mean, variance, or tail-heaviness misspecification can still appear as shape predictability.

All three contrasts are mandatory: candidate versus constant shape by Brier score, versus historical training frequency by Brier score, and versus constant shape by full normalized-return negative log density. The frequency control makes no density claim. Both phases must meet the registered absolute improvements, both evaluation slices must improve, and all wave and cumulative gates must pass. The wave has three comparisons, with 106 cumulatively; 99,999 draws give a minimum raw bootstrap p-value of 1/100000, below one tenth of the first wave Holm cutoff 1/3360. Literal block lengths 21/63/126 and HAC126 require at least 127 phase observations. Reused history and archival sources limit any passing result to an exploratory lead.

The four new publication fault tests pass, as do the 16 density tests; scoped lint passes. Synthetic partial registration, partial evaluated-ledger publication, report failure, and protocol mutation each force all three canonical comparisons to p=1, status `UNEVALUABLE`, and no lead. Completed source/support/fit artifacts remain available; computed scores survive only as explicitly unpublished diagnostics. Partial report text is replaced, and complete unevaluable ledger records retain trial accounting. No earlier frozen files were edited.
