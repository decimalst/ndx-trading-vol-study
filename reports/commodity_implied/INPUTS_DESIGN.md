# Authenticated commodity forecast inputs

Eight generated input tests were written before implementation and the missing-module RED was recorded. This reader is for the later registered experiment; neither implementation nor its generated tests read real source histories.

The caller binds the exact raw/parsed history inventory to the completed source-admission certificate. The reader validates both symbols, safe distinct paths and all four byte hashes before decoding any numerical value. It parses JSON numerical tokens as text to validate both complete parsed-record date envelopes against the unchanged 2009-01-02 through 2025-10-20 bounds. Only then does it decode the bounded numerical values and independently reconstruct each complete parsed schema from its original raw bytes. Duplicate JSON keys and nonfinite constants fail. File reads use the authenticated byte snapshots throughout; files are never changed.

The output has exact uppercase OVX/GVZ columns on the sorted outer union of their own source dates. Explicit missing observations and absent source dates remain unknown, without filling or selecting a predictive cohort. Feature construction later reindexes to the full QQQ calendar and applies the declared delay. The reader does not authenticate original publication vintages, choose sample support, or authorize a forecast run.
