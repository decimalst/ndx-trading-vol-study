# Independent commodity score and calibration verification

This component is prospective and synthetic-only before root's empirical freeze and registration. It owns no forecasts, source inputs, model fitting, publication, or new hypothesis choices. `verify_scores(panel, calendar, metrics, prior, protocol)` reconstructs the daily statistical artifact and returns VERIFIED or raises. `verify_calibration(protocol, result)` reconstructs the declared generated stationary-null experiment. Neither function imports a producer scoring or forecasting routine.

The read-only commodity protocol declares candidate-versus-matched and candidate-versus-market, in that order, at one five-session target. Both comparisons use exactly paired market/matched/candidate rows. Targets, phase, endpoint, commodity cutoff, fitting dates, training counts, and original-calendar modulo-five offsets must agree across arms. Calendar membership, the exact fifth-session endpoint, previous-session commodity and training cutoffs, monthly fit links, positive finite forecasts/targets, and QLIKE are checked. The score verifier checks saved fit metadata and paired identities; the separate forecast verifier reconstructs the complete training history and omitted/unscored application coverage.

The two phases use development origins 2016-01-01–2019-12-31 with labels mature by 2019-12-31, and evaluation origins 2020-01-01–2025-10-20 with labels mature by source end. Evaluation stability slices are 2020–2022 and 2023–source end. Production floors are 505 paired observations per phase, 252 per evaluation slice, and 63 per modulo-five offset in each phase. Every support failure aborts verification. There are no weekly releases, release-count floors, or equal-release weighting. Annual calendar/retained/missing counts disclose date gaps; circular blocks operate on retained paired observations in date order.

Bootstrap blocks are 21, 63, and 126, with 399999 draws. The seed is 20260930 + 5000000 + phase_code*10000 + block, phase codes 0/1. Each draw uses shared resampled origin positions for both comparisons. Reported bootstrap p-values use a two-sided centered null with ties and plus-one correction; intervals are the 2.5%/97.5% quantiles of resampled means. Bartlett HAC uses 126 lags. Each phase probability is the maximum over all blocks and HAC, and each hypothesis probability is the maximum over both phases. The interval envelope spans all four intervals. HAC standard error, nominal 80% power MDE, and every individual p-value/interval are reconstructed.

Exactly 142 inherited records are retained unchanged; the two new records create a 144-hypothesis cumulative family. The new two-row Holm correction uses wave alpha .05/(24*25); cumulative Holm uses all 144 probabilities at .05. A comparison must pass both corrections, have mean absolute QLIKE delta <= -.005 in both phases, and have strictly negative delta in every offset and evaluation slice. Both comparisons must pass for the sole `commodity_implied` lead. Every phase, annual, offset, slice, envelope, probability, count, identity, verdict, and top-level field is independently reconstructed. Probabilities and inherited identities compare exactly; other score numerics use the prospective absolute tolerance 1e-10 and relative tolerance 1e-8. The full literal production protocol is pinned by root's entry layer; smaller explicit generated protocols exercise test branches without changing that literal.

Calibration uses rho .8, n 1500, burn-in 200, 200 replications, 499 bootstrap draws, and minimum envelope coverage .9. For each replication, stationary AR(1) innovations are drawn before the initial stationary state; the retained series follows burn-in. Calibration bootstrap seeds are base_seed + trial*1000 + block, without the forecasting phase offset. Individual block coverage, union-envelope coverage including HAC, settings, seed, status, and limitation are checked exactly. This one generated null is not market-data coverage certification.

The implementation reuses frozen `verify_claims_release_scores` numerical/date/comparison primitives, but replaces the claims aggregation and gates. Inherited rows require complete identity, exact nonnegative source row indices, valid lowercase source SHA256 values, uniqueness by source/index, and one consistent hash per source; arbitrary inherited extra fields remain unchanged. Source contents are authenticated by root's separate pinned entry layer, not loaded by this checker. Synthetic expected artifacts use explicit individual circular-observation resampling and HAC/ordering oracles from the frozen independent statistical test module, plus new literal daily panel grouping. Neither expected calculations nor this verifier call the producer scorer.

They cover known signal, a serial null, paired/date/loss corruptions, each support/gate branch, all inference and accounting fields, exact probability comparison, inherited preservation, shared draws and seeds, and calibration corruption. `SCORE_VERIFICATION_RED.log` records the actual absent-module failure before implementation; `SCORE_VERIFICATION_FIRST_IMPLEMENTATION.log` preserves the first pass.
