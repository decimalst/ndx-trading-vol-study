# Commodity source parser: prospective contract

The synthetic tests are written before the new parser exists and before admitting any downloaded numerical history. A retained original-byte SHA-256 must authenticate each payload. Strict UTF-8 (optional initial BOM), an exact DATE/symbol header, two-field CSV rows and valid strictly ascending unique dates are mandatory over the complete file. Empty physical rows may be ignored. Complete date-only preflight must finish before any retained numerical cell is converted. Out-of-window numerical tokens are never converted or returned.

The only symbols are OVX and GVZ. Strict ISO query bounds must lie inside 2009-01-02 through 2025-10-20. Source dates allow literal ISO dates or US month/day/four-digit-year notation without surrounding whitespace. Source line numbers retain csv.reader.line_num physical-line accounting. Finite strictly positive ordinary decimal/exponent values are observed; only an empty token or a period is missing. Zero, negative, overflow, nonzero underflow, nonfinite and nondecimal tokens fail. No filling, clipping or epsilon repair is permitted. Header-only and empty retained windows are valid source structures, not evidence of forecast support.

The parser returns the agreed parsed-but-not-independently-verified records and metadata schema. A separate implementation must reconstruct and compare every field before admission. Independent verification and acquisition receipts do not establish immutable historical vintages. No source check authorizes a predictive run, alters the family of 142 comparisons, or opens protected equity outcomes.
