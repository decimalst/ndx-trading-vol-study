Every other byte is preserved. The transformation receipts pin the original and derived hashes, removed byte spans, original parser error, evidence identifiers and resulting metadata. The existing 20-test archive contract was already green; no parser or test changes were made for these exceptions.

The unchanged parser accepts the derived 2012 copy with 52 dated links and the derived 2019 copy with 50. This is an explicit metadata exception; the strict parser was not made to accept inconsistent filename years.
