# First-report claims and five-session QQQ variance

This wave asks whether the latest original unemployment-claims report adds forecasting value beyond established market predictors and controls for the recent claims level and publication timing. It tests one signed deviation from the mean log of the four preceding first reports. The detailed [prospective derivation](../PREDICTIVE_DESIGN_DRAFT.md) and [source disposition](../SOURCE_DISPOSITION.md) precede predictive calculations. The executable contract is `claims_release.yaml`.

The source ledger has been independently verified across 856 reference Saturdays: 851 supported first values, one unresolved corrected report and four explicit absences. Source counts are not forecast-support counts. Only original DOL release dates strictly before the origin admit a count, with ages one through seven calendar days. Missing latest values or any missing week in the five-report chain make the claims state unavailable; there is no fallback. Comparison-side ALFRED values and dates are audit-only.

Three separate log-target OLS models share exactly the same rows: the established 12-column market baseline; that baseline with prior claims level, release age and entry weekday controls; and the matched model with the one new deviation. Training-only population scaling and separate exact Duan smearing are fixed. Monthly fitting uses the first feature-complete origin and only targets matured by the preceding full-calendar market session. Rank or scale failure aborts the registered wave without dropping columns or changing estimators.

The sole target is the arithmetic mean of the next five observed-session daily OHLC variance proxies. Development origins span 2016–2019, with labels matured by 2019-12-31; evaluation origins span 2020–2025-10-17, with labels matured by 2025-10-20. The full reference calendar determines lags, target endpoints, maturity cutoffs and modulo-five offsets. All complete application forecasts are saved, including those without evaluable future labels.

Both candidate-versus-matched and candidate-versus-market comparisons must improve absolute mean QLIKE by at least 0.005 in both phases. Each monthly fit needs 1,000 mature origins and 200 distinct releases. Each phase needs 505 origins and 104 releases; each fixed evaluation slice needs 252 origins and 52 releases; each modulo-five offset needs 63 origins. Every offset, evaluation slice and equal-release-weighted phase mean must favor the candidate.

Inference uses 399,999 shared circular-bootstrap draws for each block length 21, 63 and 126 retained observations, plus Bartlett HAC126. Phase probabilities take the maximum across all methods; each hypothesis takes the maximum across development and evaluation. Both Holm2 probabilities must be below 0.05/(23*24), and both cumulative Holm142 probabilities below 0.05. Every prior comparison remains counted. A registered unevaluable attempt retains both new probabilities at one.

Before market-cohort admission, generated serial-null calibration, independent calibration reconstruction, synthetic component/integration tests and the full repository suite must pass. Independent verification reconstructs source features and timing, all monthly cohorts and fits, scored and unscored forecasts, losses, inference and family accounting. The freeze records exact artifacts and numerical tolerances; no configuration is chosen using this wave's results.

The numerical source ceiling remains 2025-10-20, with market observations from 2025-11-03 onward protected. These are reused historical partitions, current captures of agency archives and existing vendor market extracts. Original intraday availability, immutable source vintages and the daily risk proxy retain their stated limitations. A pass would identify an exploratory model-relative lead, not a causal labor effect, consensus surprise, executable profit or future-validated signal.
