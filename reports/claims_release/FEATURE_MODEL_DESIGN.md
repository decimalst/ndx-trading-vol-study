# Generated claims feature and fixed-model contracts

Written before implementation, 2026-09-08. No historical ledger, market value, cohort, fit or score is read. Current PREDICTIVE_DESIGN_DRAFT and SOURCE_DISPOSITION govern: DOL release date is the sole claims availability clock; source_comparison is opaque audit metadata.

`build_claim_features(reference_calendar, ledger_rows)` preserves the exact DatetimeIndex and emits, in order, claim_m4, claim_age, entry_dow_1..4, claim_x, claim_reference_week, claim_release_date, claim_age_days, claim_status. claim_age is already age/7; raw age_days is diagnostic only. Unknown m4/age/x remain NaN while known weekday indicators remain populated. Selected dates and age remain visible on stale or unresolved rows. Reasons distinguish no prior release, stale release, latest unresolved value, missing prior week, prior unresolved/no-admitted value and prior not-yet-released report.

Validate all calendar/ledger dates through 2025-10-20 before feature logarithms. Require unique ordered naive midnight calendar instants, unique Saturday reference weeks and unique known release dates; do not compress or fill. Select the latest strictly prior DOL release before value checks. Require age1..7 and all four exact preceding Saturday records, each observed and published before origin. Only first_report_value can enter a logarithm; unresolved audit-side counts are never traversed or converted.

`fit_models(train_features, train_y, apply_features)` returns predictions and fits keyed market/matched/candidate. Fixed MARKET is the12 declared market columns; MATCHED adds claim_m4,claim_age,entry_dow_1..4; ALL adds claim_x. claim_age is consumed as supplied, with no second division. All19 numeric fields must be complete before any arm fits; extra provenance columns are ignored. The caller owns expanding monthly cohort/maturity and1000-row/200-release support. The numerical core checks sufficient algebraic rows, exact intercept, population scales>1e-12 and relative SVD rank1e-12. It separately fits each log-target OLS and exact training-residual Duan smearing with stable log-mean-exp; no regularization, clipping, dropping or fallback.

Each model audit records ordered feature names, named standardized coefficients, non-intercept population means/scales, singular values/rank, log smearing, normal-equation residual and train/application counts. Predictions remain arrays. Original DataFrames/targets are unmodified; target Series must align exactly. Nonfinite or nonpositive forecast arithmetic invalidates the call.

Prewritten generated tests cover DOL-only timing, release day/expiry/holidays, missing and unresolved first reports, opaque conflicting audit sentinels, consecutive weeks, future noninterference, source fences, exact formulas/schema and calendar preservation. Model tests use an independent raw-design QR oracle, saved-audit reconstruction, separate smearing, query noninterference, target/feature unit transport, strict typed/common-row validation, rank/scale failures and extreme arithmetic. Missing-module RED precedes implementation; focused GREEN and lint precede any proposed historical use.

Completed result: **26 generated tests passed in 0.067 seconds** (14 feature/timing and12 model/math tests); focused Ruff is clear after formatting only these four new files. `FEATURE_MODEL_RED.log` preserves the missing-module failures before either implementation existed, and `FEATURE_MODEL_GREEN.log` records the completed run. No historical ledger, market panel, support calculation or predictive fit was loaded. Final model audit keys are feature_names, coefficients, feature_means, feature_scales, singular_values, rank, rank_relative_cutoff, log_smearing, normal_equation_max_abs, n_train and n_application. The stored coefficient convention is the standardized design with an unchanged constant-one column; means/scales cover only non-intercept features.
