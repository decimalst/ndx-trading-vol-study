Independent claims score verification: generated contracts and evidence

The verifier owns no source admission, feature calculation, fitted prediction or publication step. It reconstructs the two fixed QLIKE contrasts from the supplied common prediction panel, all declared support and sign/effect gates, uncertainty summaries, both multiple-testing families and the joint lead decision. It imports only standard-library copy, NumPy, pandas and scipy.stats.norm; it does not import or call the scoring producer or any producer inference helper. Only generated fixtures are used; no real cohort or score is loaded by this task.

Prewritten numerical tests establish shared circular bootstrap designs across both contrasts, exact retained-observation length and remainder sampling, RNG ordering (all full-block starts before all tail starts), centered two-sided plus-one p-values, Bartlett HAC autocovariances with denominator n and clipped nonnegative long-run variance, 95% intervals and nominal 80%-power MDE, both Holm family sizes, and offsets computed from the unchanged full calendar before filtering. Exact output-schema, paired-panel, source-identity, phase, support and verdict tampering tests use the parent-provided fixed metrics schema. All 27 test methods, including calibration contracts, were written while the verifier module was still absent.

The API `verify_scores(panel, calendar, metrics, prior, protocol)` returns a VERIFIED dictionary containing hypothesis_count=2, cumulative_hypothesis_count=142 and the integer common_scored_origins. It otherwise raises ValueError, including INSUFFICIENT_DATA for any whole-wave support failure. It validates the complete three-arm common panel, recomputes QLIKE from positive targets/predictions, checks the fifth full-calendar target endpoint, phase maturity fences and offsets, and reconstructs every nested output field. Minimum-training/model validation remains with the independent forecasting verifier; this checker enforces shared supplied training metadata without introducing a new training gate.

The formal contrasts remain candidate-minus-matched and candidate-minus-market, in that order. Each phase has the maximum of all block and HAC p-values; each comparison takes the maximum across phases. Its interval envelope contains every block percentile interval and the HAC interval. Phase and slice observation/release floors and all five phase-offset floors are mandatory. Practical effect uses delta <= -effect_threshold_absolute, while offset, slice and equal-report-weighted means require strictly negative delta. Each inherited hypothesis and its source/status metadata are retained unchanged in the 140-row prior family. Holm-2 uses the wave threshold and Holm-142 uses the cumulative threshold, both with strict significance inequalities. A lead exists only if both comparison verdicts pass. Failed effect or sign gates are valid completed negative outcomes, never support errors. Annual coverage includes each year present in the phase-bounded full calendar, including a year with no scored origins; its mean is null, counts are zero, and every bounded calendar origin is missing.

The API `verify_calibration(protocol, result)` independently reconstructs the declared AR(1) null and returns `{'status': 'VERIFIED'}` only when the complete result matches. Each trial draws all n+burn_in shocks before its stationary initial state from one shared seeded generator, follows the declared recursion, discards exactly burn_in states, and reconstructs HAC and block coverage. Calibration block seeds use base + trial*1000 + block, without horizon/phase offsets. Coverage and PASS/FAIL thresholds, flattened design, seed and limitation text are all checked. Synthetic tests use seven trials of 60 observations, ten burn-in states and 59 bootstrap draws, and explicitly inspect the generated path and resampler seed sequence. The actual 200-trial calibration remains parent-owned and was not run by this task.

Numerical reconstruction uses atol=1e-10 and rtol=1e-8 for ordinary floating summaries; p-values are compared exactly, while dates, counts, identities, dictionary schemas and decisions must match exactly. Calibration fractions and metadata also compare exactly. Independent verification failure never replaces a negative outcome with a positive result or modifies producer output.
