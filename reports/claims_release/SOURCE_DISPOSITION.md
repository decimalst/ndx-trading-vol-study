## Source clock and missingness

The forecasting source will be the authenticated original DOL first-report ledger. Its displayed release date governs the conservative date-only availability rule. ALFRED's real-time date remains comparison evidence; it is not an independent ingestion timestamp and must not gate a DOL value that ALFRED never archived in that form. The March 2018 first value and the later revised ALFRED value are different records, not two timestamps on one value.

The design's previously proposed first-later-session rule, seven-calendar-day maximum age and five-consecutive-reference-week requirement remain prospective until the forecasting protocol is frozen. No older complete report may replace the latest eligible unknown state. The 2017 quality gap applies to every arm on identical rows; it was identified from source evidence without observing any claims-model outcomes. The source calendar itself is never compressed.

This rule resolves a documented source limitation before predictive registration. It does not relax an empirical gate or rescue a scored model. If the resulting fixed model lacks training/support, the later registered comparison must retain that failure under its unchanged rules.
