# Generated end-to-end claims integration

This bounded test is written before its first integration execution. It uses only `synthetic_inputs()` from the independent forecast test module as a data generator; none of that module's expected computations or assembled output oracles are called. The invented sources span 2010–2011 with stochastic OHLC, adjusted prices, volume, independent cross assets and IV, plus varying Wednesday/Thursday claims releases. Forecast history and support settings are small and explicit. Inference uses 39 draws, blocks 3/7/11, HAC 7 and small generated support floors. The exact production protocol validator is neither changed nor used with these settings.

Both tests run actual market features, causal claim features, the full-calendar target, the monthly three-arm OLS pipeline, independent forecast reconstruction, paired scoring and independent score reconstruction. The second adds missing IV/cross dates and an unresolved first report whose comparison-side counts are intentionally unusable. It checks missing-origin disclosure and exclusion of unresolved training states through the combined implementation.

The complete payload is then round-tripped through temporary Parquet tables and JSON fit/metric artifacts and independently checked again. Tests require three scored arms, retained unscored applications, two fixed contrasts, preservation of all 140 invented prior probabilities and the total 142, with no expected positive discovery or forced statistical outcome. Verification must leave producer outputs unchanged. No genuine sources, historical cohort, historical fit, registration or full repository suite is executed.
