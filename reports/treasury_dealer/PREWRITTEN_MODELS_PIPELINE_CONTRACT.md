# Prospective Treasury model and monthly pipeline contract

Written before either new implementation or any historical Treasury feature, cohort, fit or forecast access. Only generated inputs are authorized for this component. All frozen commodity, claims and other modules remain unchanged. The new implementation adapts the frozen commodity model and pipeline; this is producer work, not an independent historical verifier.

## Fixed model specification

`fit_models(train_features, train_y, apply_features)` returns exactly `predictions` and `fits`, each keyed `market`, `matched`, `candidate`. MARKET has the existing 12 columns: const, lrv_d, lrv_w, lrv_m, lev_d, lev_w, lev_m, liv, lvix, term, xasset_stress, market_stress. MATCHED appends, in order: tlt_ret, tlt_r2, tlt_lrv5, tlt_lrv22, weekday_1, weekday_2, weekday_3, weekday_4, auction_count, tenor_3, tenor_5, tenor_7, tenor_10, tenor_30, reopening_count, log_offering_sum, high_yield_sum, bid_to_cover_sum, prior_share_mean_sum. CANDIDATE appends dealer_surprise. Arm dimensions are 12, 31 and 32 including the intercept.

Every arm uses all supplied common rows, with all 32 named numeric columns finite and const exactly one. Duplicate rows/columns, bool/non-numeric features, misaligned target Series, nonpositive/nonfinite targets and fewer than 32 training rows fail. Extra provenance columns are ignored without mutation. The pipeline supplies the actual 1000-row support floor. The numerical core makes no feature, calendar or source calculations.

Reuse the pinned generic `claims_release_models._fit_arm` and `_targets` with explicit disclosure: training-only population means/std, nonintercept scale strictly above 1e-12, unpenalized standardized log-target least squares with relative SVD cutoff 1e-12, full rank required, and each arm's exact training-residual Duan smearing computed via log-sum-exp. No column dropping, zero-scale fallback, clipping or alternate solver. All application predictions, including unscored ones, must be finite and strictly positive. Audit keys retain feature_names, coefficients, feature_means, feature_scales, singular_values, rank, rank_relative_cutoff, log_smearing, normal_equation_max_abs, n_train and n_application.

## Calendar, cohort and output contract

`build_panel(features, targets, config=None)` and its exact alias `run_pipeline` accept already-built full-calendar feature and target frames. Targets have exactly y and target_end; all 32 model columns plus treasury_cutoff_date are required. Both frames use the same nonempty unique increasing native naive-midnight full observed QQQ calendar. Endpoints equal the fifth subsequent full-calendar session, with no finite target where the endpoint is unknown. Missing feature rows never compact that calendar. Treasury cutoff is precisely the previous full-calendar session if that date is at least 2010-01-01, otherwise NaT; a complete model row requires known cutoff. This component verifies this metadata, not the upstream feature construction or source release clock.

Default config has origin_start 2016-01-01, origin_end/source_end 2025-10-20, development [2016-01-01, 2019-12-31], evaluation [2020-01-01, 2025-10-20], minimum_train 1000. Config has exactly those six keys. Smaller generated windows/floors are supported; the source lower bound and 2025-10-20 ceiling cannot widen, phases are ordered/nonoverlapping and within the origin window, and the training floor is an exact positive int. Development labels must end by the development end; evaluation labels by source_end, even if the evaluation origin window ends earlier.

For every requested calendar month, select the first feature-complete requested origin without inspecting its target or phase. Its previous full-calendar session is the training cutoff. Common training rows have complete 32 features, earlier origin, finite positive y and target_end at or before that cutoff. All feature-complete requested origins in that month receive all three predictions, including phase-unassigned, label-missing and immature targets. All months are planned before fitting. An insufficient scheduled month aborts the whole attempt with INSUFFICIENT_DATA, full coverage and schedules, and no forecasts; it cannot silently skip to later months. Months without calendar origins or complete features are explicitly recorded.

The return keys remain applications, panel, coverage, schedules (DataFrames), fits (list). All frozen commodity schemas are retained with commodity_cutoff_date renamed treasury_cutoff_date and no claims/release counts or weighting. Applications and coverage sort by origin; panel sorts by origin then market/matched/candidate; monthly schedules and fit records sort by month. Dates normalize to ns, counts/offsets to nullable Int64. Offset is full-calendar position modulo five. Fits retain exact ISO training/application origin lists and each arm's model audit. Coverage exposes every requested origin and missing feature names in the fixed ALL order. Status priority is incomplete_features, attempt_aborted, outside_phase, target_not_mature, missing_target, target_after_phase_cutoff, scored. QLIKE is y/prediction - log(y/prediction) - 1, with invalid arithmetic fatal.

## Prewritten generated checks and limitations

The eight model tests include an independent raw-design QR expectation oracle, audit reconstruction with separate arm smearing, query-independence, all-common-column validation, exact scale/rank failures, target/feature unit transport, overflow/empty applications and input preservation. The seventeen pipeline tests cover the alias/schema, label-blind first query, exact common mature cohorts, future-target poisoning, missing-row offsets, all censoring states, evaluation target fence, explicit empty/incomplete months, whole-attempt support failure, invalid unscored predictions, QLIKE arithmetic, exact endpoint/cutoff identity, source-floor semantics, numeric/calendar/config validation, datetime-unit transport, and generated integration through the actual model core. These tests establish generated numerical/cohort behavior only; they are not empirical validation, source admission, an independent forecast certificate, registration or evidence of predictive benefit.
