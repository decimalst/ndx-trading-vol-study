# Admitted-data model alternative: bounded independent review

Design review only, 2026-09-08. No new source acquisition, source-value arrays, protected QQQ/SPX observations, feature/cohort construction, fits or scores were accessed. This note changes no frozen protocol or result and registers nothing.

**Recommendation: one observable-state precision gate between the established baseline and its fixed 252-session-half-life adaptive OLS counterpart.** It addresses model reliability conditional on the current state using existing information. It is a new modeling mechanism, not a new external signal. Both individual experts and a fitted constant gate are necessary controls. This is deliberately smaller than another architecture or foundation-model sweep.

## The linked references and the remaining gap

[Moirai 2.0](https://arxiv.org/abs/2511.11698) supplies a pretrained quantile-forecasting model; the pinned small checkpoint and causal calibration were already run here. [xLSTM-Mixer](https://proceedings.neurips.cc/paper_files/paper/2025/hash/09e38101e74a89129ccd0d0756ed36b3-Abstract-Conference.html) combines a linear forecast with recurrent mixing; a disclosed small CPU adaptation and matched NLinear were already run. Neither historical exercise established improved benchmark-relative QLIKE. These were specific implementations, not exhaustive architecture exclusions.

[TimeCopilot](https://arxiv.org/abs/2509.00616) is an orchestration/model-selection framework; it was reviewed, not an additional scored model. [Time-Series-Library](https://github.com/thuml/Time-Series-Library) is a useful implementation collection, including patch/attention models; no complete library sweep was run. [Timer-S1](https://arxiv.org/abs/2603.04791) has 8.3 billion total parameters and was deferred under the earlier documented resource constraints; it was not scored. This review did not remeasure resources or download weights. Repeating automated selection on inspected history would enlarge the search, and pretrained models retain exposure uncertainty. The precision gate needs neither a new package nor a pretrained checkpoint.

The old dynamic ensemble uses six fixed experts and softmax of recent matured average losses with a 252-session window, 63-session half-life and 10% equal-weight floor. It does not estimate how reliability changes with the current observable market state. The old latent memory retrieves historical error ratios by fixed Euclidean geometry after an unsupervised eight-PC TiRex projection. It does not fit this state-dependent precision combination. Code and protocol inspection found no existing precision gate with the following nested mechanism. This is a bounded novelty statement about the inspected repository, not a claim of a new statistical invention.

## One concrete candidate

Use exactly two experts: unweighted log-target OLS with exact Duan smearing, and the same 12 market predictors with fixed 252-session exponential training weights and identically weighted smearing. The pair is chosen to isolate current-state reliability of gradual adaptation, rather than to select a historical winner. Predict the arithmetic mean of the next five complete full-calendar QQQ GK-plus-overnight variance proxies, in native squared-return units. Retain the current strong 12-input baseline, source ceiling 2025-10-20, development 2016–2019 and evaluation 2020–ceiling. Reused dates remain exploratory.

Let b and a be positive forecasts issued by baseline and adaptive OLS, let s=lrv_d−lrv_m be current known log-risk acceleration, and z=tanh(s). There is no target-dependent state, fitted threshold or state grid. Define x_low=(1−z)/2, x_high=(1+z)/2, w=x_low*c_low+x_high*c_high, with both coefficients bounded in [0,1]. Set r=b/a, p=1+w*(r−1), and forecast v=b/p. Equivalently, 1/v=(1−w)/b+w/a. This is a positive harmonic mixture lying between the two experts; it cannot manufacture arbitrarily large corrections.

Fit the two coefficients to previously issued, mature forecast/target triples by minimizing mean[(y/b)*p−log(p)] + .005*(c_low²+c_high²). QLIKE differs from this data term only by a coefficient-independent constant. Since p is positive affine in the coefficients, its data Hessian is mean[g*gᵀ/p²], where g=(r−1)*(x_low,x_high), and the penalty adds .01*I. The problem is strictly convex on the box and has a unique optimum. The fitted constant control constrains c_low=c_high=c; its penalty is exactly .01*c², so it is mathematically nested. Constant identical experts uniquely give zero coefficients. Finite ratios/arithmetic and constrained stationarity must be verified without fallback or clipping.

There are exactly **three proposed comparisons**: contextual gate versus baseline, adaptive OLS and constant gate. A lead must beat both experts and the constant gate; only the latter isolates conditional reliability beyond average mixing. The design does not claim to beat the old six-expert loss-only ensemble, and it does not test learned latent retrieval. No alternate state, expert subset, horizon, half-life, penalty, architecture or parameter grid belongs in this attempt.

## Safe issued forecasts are required

Do not directly reuse the old component cache as a new issuance ledger. `src/model_memory_study.py:160` makes its query mask depend on finite future target and target_end<=latest_target, then selects each month's first query from that mask. Its training maturity also permits target_end at the fit origin. The exact frozen experiment and prior verification remain untouched, but that construction is insufficient for this new target-blind issuance contract.

Generate new baseline/adaptive forecasts from the already admitted market inputs through the newer full-calendar monthly schedule: choose first feature-complete query without its label; train only on common complete rows with five-session labels mature by the previous observed session; require 1000 expert-training rows; issue predictions for all complete origins including unscored/immature ones. Preserve all missing calendar dates and provenance. No TiRex, Moirai or new Treasury information is needed.

For a bounded prospective gate proposal, use the last 1260 full-calendar sessions of actually issued pairs, require 252 mature complete pairs, and refit both gates monthly on exactly the same eligible records using the previous-session cutoff. Before 252 eligible pairs, explicitly issue the baseline gate (both coefficients zero) and retain that cold-start status; do not use missing labels as a scheduling selector. Keep cold-start applications and scored origins in the common comparison with status/count disclosure. The fixed expert issuance start and cold-start calendar must be declared in the new protocol before any support inspection; changing them afterward is a separate documented amendment. Later support failures do not authorize changing the window or dropping controls.

## Tests and run path

First write synthetic tests for the exact QLIKE/objective constant identity, analytic gradient/Hessian, independent constrained optimum, constant nesting, identical experts, boundary solutions, unit invariance, positivity, input rejection and application independence. Test state and future-target poisoning, full-calendar maturity/offsets, first query blindness, missing targets, cold-start transition and exact record identities. Independent verification must reconstruct all issued expert fits, gate membership/coefficients, scored and unscored forecasts and paired inference; checking only published scores is insufficient.

After the pure core and scheduler/integration tests pass, freeze the new protocol, input/code/test pins and all old artifacts, then register the three comparisons and run once. Retain contemporary gates: absolute QLIKE improvement at least .005 in both phases, negative differences in each fixed later slice and every modulo-five offset, required support, paired blocks21/63/126, HAC126, generated calibration, wave and cumulative Holm. The wave number and cumulative family must reflect whichever Treasury or alternative attempt is actually registered first; if no intervening trial is registered, these three would extend144 to147. Any numerical/support failure retains all registered entries as unevaluable; it never becomes a silent optimizer or model substitution.

A passing historical result is an exploratory lead, not trading validation or confirmation from the sealed period. Do not access observations beginning2025-11-03 for this exercise. This small experiment directly revisits the user's model-layer question while remaining computationally modest and avoiding another source-engineering detour.
