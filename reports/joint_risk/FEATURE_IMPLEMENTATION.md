# Joint-risk feature implementation: prefit evidence

Only synthetic fixtures were evaluated for this implementation. No empirical source loading, numerical measurement audit, features, paired outcomes, fits, or scores were run. The feature module and tests are new; frozen relative-risk source/tests remain unchanged.

The initial absent-module failure is retained in `features_initial_red.txt`. A prefit review also required an observed open/close overflow to fail even when high/low is missing; its separate failing regression is retained in `partial_ohlc_initial_red.txt`. All 24 contracts subsequently passed, and scoped Ruff passed; the commands, output, and byte hashes are retained in `features_implementation_checks.txt`.

`src/joint_risk_features.py` exports `ROOT`, `BASE`, `ADDITIONS`, `ALL_FEATURES`, `MODELS`, `load_sources`, `measurement_audit`, `require_measurement`, and `build_features`. `BASE` is the frozen relative-risk 28-column design, including raw `corr22`. `ADDITIONS` is, in order, `qqq_day_d`, `qqq_day_w`, `qqq_day_m`, `spx_day_d`, `spx_day_w`, `spx_day_m`. These are arithmetic means of each asset's signed raw log close/open return over strict 1/5/22 SPX-reference observations, shifted one reference session. `ALL_FEATURES` therefore has 34 columns. No correlation square or global center is constructed here. `MODELS` is `constant_matrix`, `constant_correlation`, `dynamic_correlation`; their fitting belongs to the separate model module.

`build_features(qqq, spx, iv)` returns all 34 columns plus `feature_cutoff_date`, followed by a target frame with `y_qqq`, `y_spx`, `target_end`, and `available_date`. Each paired outcome is the next actual observed SPX session's raw log close/open return. Both timestamps equal that session; the terminal row has unknown labels and dates. Signed and exactly zero returns remain unchanged. No next-common-session substitution occurs. Missing open/close produces an unknown return; a high/low-only gap leaves close/open computable and makes inherited GK histories unknown. The caller owns the common paired finite-row mask.

The full-calendar measurement audit precedes any feature construction. It preserves every frozen GK rule and field, and adds `finite_intraday_return_rows` and `zero_intraday_return_rows` within each `per_asset` object. Both count complete OHLC rows on the full SPX calendar, independently of later feature eligibility. Nonfinite computed signed returns raise an error whenever both open and close are observed, including high/low-incomplete rows. Missing high/low therefore cannot hide a numerical overflow. The requirement function checks the frozen GK gate and requires the signed finite count to match the complete-OHLC count, with a zero count between zero and that count. A finite GK floor failure remains an audit object that callers can persist before rejecting the whole wave. No clipping, row deletion, or missing-value substitution is introduced.

`load_sources(protocol, root)` reuses the frozen relative-risk loader. Its six raw-source paths, byte hashes, date fences, observed calendars, missingness, asset identities, and archival-vintage caveats are preserved. Only the new audit's `raw_columns`, `target_interpretation`, and `measurement_gate` descriptions change. QQQ is an ETF; SPX is the vendor's `^GSPC` price index. The paired return observations are not measured high-frequency covariance. Raw close/open ratios are invariant to common price-unit changes; this does not certify source vintage or ETF/index economic equivalence.

The tests cover exact inherited controls, signed means and lagging, actual-session maturity, zero returns, missing target sessions and strict windows, source predecessor mismatches, high/low versus open/close missingness, full-calendar GK failure before base construction, malformed signed-audit counts, nonfinite signed computation, asset permutation, price units and unused adjusted close, current/future mutation, date ordering, source-byte audit preservation, and date filtering before numerical parsing. These checks establish implementation contracts on fixtures, not predictive value or real-source completeness.
